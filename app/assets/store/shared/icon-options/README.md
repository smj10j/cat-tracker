# App Icon Options — Lamplight Direction

These are concept SVGs for the Whisker Health app icon refresh (PRD-visual-identity-v2 Phase 4). Each explores the Lamplight amber-on-aubergine identity.

**Decision status:** Options only — the live app icon is NOT being swapped yet. These are for product-owner review. A future PR selects one and generates the required 1024×1024 PNG.

## Concepts

### 1. `lamp-whisker.svg` — Warm lamp with cat whisker silhouette
A stylized amber lamp shape on deep aubergine, with three whisker lines extending from the light source. The lamp = vigilance; the whiskers = the cat. Simple, geometric, reads at 29px.

### 2. `amber-heart.svg` — Amber health heart with cat ear silhouette
A heart shape in Lamplight amber (#F2A65A) with subtle cat-ear points at the top, on an aubergine circle background. Combines health + cat + brand color.

### 3. `warm-circle.svg` — Concentric warm rings with cat silhouette
Two concentric amber rings (data/tracking motif) on aubergine, with a small cat head silhouette at center. The rings suggest measurement trends.

### 4. `glow-paw.svg` — Amber glow behind a paw print
A soft amber radial glow behind a simplified paw print on aubergine. The glow = the "lamplight" metaphor; the paw = cat.

### 5. `lamp-cat.svg` — Minimalist cat face lit by amber light
A simplified cat face (two eyes, two ears) in cream/white on aubergine, with one side illuminated by an amber light source from the left. The "warm lamp in a dark room" metaphor made literal.

## Design constraints
- Must read clearly at 29×29 px (iOS notification icon) and 1024×1024 (App Store)
- No fine detail — icon should be recognizable from a silhouette alone
- Colors: aubergine bg (#1B1424), amber primary (#F2A65A), cream accent (#F5EDE0)
- Must not collide with Whisker (Litter-Robot) icon which is also purple + dark
